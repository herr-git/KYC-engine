# Official texts

Download these and place them here with exactly these names. They are not committed (see the project README).

| File name | Text | Where |
| --- | --- | --- |
| `amlr-2024-1624.pdf` | Regulation (EU) 2024/1624 | https://eur-lex.europa.eu/eli/reg/2024/1624/oj |
| `tfr-2023-1113.pdf` | Regulation (EU) 2023/1113 | https://eur-lex.europa.eu/eli/reg/2023/1113/oj |
| `fatf-recommendations.pdf` | The FATF Recommendations | https://www.fatf-gafi.org/en/publications/Fatfrecommendations/Fatf-recommendations.html |

A different edition will change the fingerprints. Run `python tools/build_library.py --update-lock` only after checking every quote again.
